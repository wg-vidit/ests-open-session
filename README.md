# VIDIT Open Session
----
GitHub repository designated for the hands-on work during the open session at the ESTS conference (29 May, 2026, Lublin).

## Contents

The folder `corpora-for-testing` contains three sets of witnesses, which you can use to test and review text collation tools.

- **Dylan_SHB**: manuscript, typescript, and published song tekst of *Subterrean Homesick Blues* by Bob Dylan. Both in TXT and XML format. Including images. Folder structure arranged to meet the requirements of the Collens tool.
- **Edictus-Rothari**: four witnesses of the *Editto di Rotari*, transcribed in TEI XML.
- **Pessoa-DoP**: TXT and XML transcription of a fragment of Fernando Pessoa's *Duke of Parma*.
- **KMH15**: seven witnesses of the *Hänsel und Grethel* fairytale, transcribed in TEI XML.
